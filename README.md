# Gemini Widget

Petit widget flottant always-on-top pour Gemini Advanced.

## Setup

```bash
cd gemini-widget
npm install
npm start
```

## Utilisation

- **Clic sur la pill** → expand/collapse
- **Onglet Chat** → interface minimaliste, tape et envoie
- **Onglet Gemini** → la vraie page Gemini (pour te connecter la première fois)
- **Drag** la pill pour déplacer le widget
- **✕** pour fermer

## Première utilisation

1. Lance l'app avec `npm start`
2. Clique sur la pill pour expand
3. Va dans l'onglet **Gemini**
4. Connecte-toi à ton compte Google
5. Reviens dans **Chat** — ça utilise ta session pour toutes les requêtes
